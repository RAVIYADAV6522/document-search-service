      API

      Everything on this page comes from these JSON endpoints.

      • /search?q=budget&engine=sql ranked search (engine=sql|cosine, limit, offset)
      • /documents?tags=finance,q4 documents with every listed tag
      • /owners/own-1/documents an owner's 10 most recent documents
      • /tags/stats documents per tag
      • /owners/inactive owners with no documents
      • /healthz health check
